Project Description

ShelfToTales is a full-stack bookstore and reader-community platform where commerce meets community. It goes beyond a normal online bookstore — it's a digital home for readers where book discovery, community, sustainability, and reading progress work together.

Problem Statement & Motivation

Traditional online bookstores often operate as isolated marketplaces, lacking the social connection and community aspects that make reading enjoyable. Readers struggle to find a single platform that integrates book discovery, peer-to-peer exchange, reading progress tracking, and interactive community features in one cohesive ecosystem.

Our Solution

We built ShelfToTales to bridge this gap. Our solution provides a comprehensive ecosystem featuring:

  • Community & Connection: Virtual reading rooms, smart annotations, and peer book exchange.
  • Commerce: Full product catalog, shopping cart, checkout system, and mood-based suggestions.
  • Personalization: Virtual bookshelves, reading challenges, and an analytics dashboard.

Tech Stack

  • Frontend: Next.js 15.5, React 19, Bootstrap 5, Chart.js, Swiper, Axios
  • Backend: Java 17, Spring Boot 3.4, Spring Security, Spring Data JPA
  • Auth: JWT (HMAC-SHA256), Google OAuth2, BCrypt
  • Database: PostgreSQL (default, all profiles), H2 (test scope only)
  • API Docs: Springdoc OpenAPI / Swagger UI
  • Testing: Vitest + Testing Library (frontend), JUnit + Mockito (backend)
